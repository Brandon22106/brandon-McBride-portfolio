# Brandon R. McBride — Personal Portfolio

A responsive, single-page accounting portfolio website built with HTML and CSS for a Rutgers Business School assignment.

## Sections
- One-sentence professional introduction
- Skills and tools
- Three experience-based project examples with on-page references
- Education, experience, and contact details

## Publish to GitHub Pages
1. Create a **public** GitHub repository named `brandon-portfolio`.
2. Upload `index.html` and `README.md` to the repository root, then commit.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`, and click **Save**.
5. Use the GitHub Pages URL displayed in Settings → Pages, typically `https://YOUR-USERNAME.github.io/brandon-portfolio/`.
6. Check the live page and all navigation links before submitting.

## Assignment submission
- Repository URL: `https://github.com/YOUR-USERNAME/brandon-portfolio`
- Live website URL: `https://YOUR-USERNAME.github.io/brandon-portfolio/`

The URL patterns are examples, not live links until the repository is published. Professional work summaries are anonymized and do not link to confidential client materials.
